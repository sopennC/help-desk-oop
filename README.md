# Help Desk на Java

Это моя первая практическая по ООП, простой консольный Help Desk на Java 17.

Заявка и пользователи в папке model, уведомления и TicketService в service, а TicketRepository в repository. Всё запускается из Main.

Я открываю папку в VS Code и в терминале пишу

mvn compile exec:java -Dexec.mainClass=helpdesk.Main

Если стоит Extension Pack for Java, можно просто нажать Run над main.
